01

The idea

Useful metadata when you need it.
Gone when you don't.

DIMFF keeps image metadata work local, direct, and understandable. Open an image, see what is embedded, change supported fields, or re-encode it without carrying the original metadata forward.

02 / Capabilities

Built around the
metadata itself.

One small utility, two clear jobs: understand the data and remove what you no longer want attached to the image.

01

CLEAN

Strip metadata in a single pass.

DIMFF can re-encode supported images to remove embedded metadata. Keep the result as a new file or overwrite the original.

05 / Current boundaries

Know what DIMFF
doesn't do yet.

01

Binary EXIF fields such as RATIONAL, SRATIONAL and UNDEFINED are currently read-only.

02

MakerNote data may decode inconsistently depending on the camera that produced it.

03

PNG metadata support is limited because PNG does not use the same EXIF structure as JPEG and TIFF.

04

GDI+ re-encoding can affect uncommon or unusual embedded color profiles.
